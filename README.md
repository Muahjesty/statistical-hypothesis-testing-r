
# 🎲 Fooled by Randomness: Permutation Testing & Confidence Intervals

A non-parametric hypothesis testing project investigating whether observed patterns in global data are statistically significant or merely artifacts of random variation and narrow subsetting.

---

## 💡 Project Purpose

Data mining narrow subsets often creates illusionary patterns that appear meaningful but are purely random noise. This project applies **Permutation Testing (10,000 iterations)**, **Bonferroni Corrections**, and **95% Confidence Intervals** to evaluate whether subset patterns in the **World Happiness Report (2019)** dataset represent real statistical signals.

---

## 🔬 Methodology & Empirical Findings

### 1. Difference in Means (Permutation Test)
* **Research Question**: In nations with High Social Support (`Social.support > 1.2`), do High GDP countries report higher happiness scores than Low GDP countries?
* **Observed Difference**: $+0.7144$ points ($\text{Mean}_{\text{HighGDP}} = 6.2146$ vs. $\text{Mean}_{\text{LowGDP}} = 5.5002$)
* **Permutation Test ($10,000$ Reshuffles)**: $p\text{-value} = 0.0003$
* **Verdict**: **Statistically Significant** ($p < 0.05$). The observed difference is unlikely to be generated by random chance.

### 2. Difference in Proportions (Permutation Test)
* **Research Question**: In generous nations (`Generosity > 0.2`), is the proportion of high-freedom countries higher in High GDP nations compared to Low GDP nations?
* **Observed Difference**: $+0.2903$ ($29.03\%$ difference in proportion)
* **Permutation Test ($10,000$ Reshuffles)**: $p\text{-value} = 0.0155$
* **Uncorrected Verdict**: **Statistically Significant** ($p < 0.05$).

---

## ⚠️ Multiple Testing & Bonferroni Correction

When testing $m = 50$ potential exploratory hypotheses across cutoffs, the Family-Wise Error Rate (FWER) inflates significantly. Adjusting the significance threshold using the Bonferroni method:

$$\alpha_{\text{adjusted}} = \frac{\alpha}{m} = \frac{0.05}{50} = 0.001$$

| Test | Observed $p$-value | Threshold ($\alpha = 0.001$) | Adjusted Verdict |
| :--- | :--- | :--- | :--- |
| **Mean Difference** | $0.0003$ | $p < 0.001$ | **Pattern Holds** (Reject $H_0$) |
| **Proportion Difference** | $0.0155$ | $p > 0.001$ | **Pattern Fails** (Likely False Positive) |

---

## 📏 95% Confidence Interval Analysis

Calculated using standard error limits ($\text{CI}_{95\%} = \bar{X} \pm 1.96 \cdot \text{SEM}$):

* **Global Population Baseline**: $[5.2324, 5.5818]$ ($\bar{X} = 5.4071, N = 156$)
* **High Social Support Subset**: $[5.9111, 6.2323]$ ($\bar{X} = 6.0717, N = 95$)

**Interpretation**: Because the 95% confidence intervals **do not overlap**, we can assert with 95% confidence that nations with high social support belong to a distinct population with a significantly higher true mean happiness score than the global baseline.
